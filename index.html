添加到主屏幕

按设备步骤装一次，之后从桌面图标全屏打开。离线外壳暂未覆盖页面本体，冷启动需联网；页面打开后可离线记账。

iPhone / iPad（Safari）

1. Safari 打开公开链接
2. 点底部分享按钮
3. 选「添加到主屏幕」→ 添加
4. 之后从桌面图标打开

Android（Chrome）

1. Chrome 打开公开链接
2. 点右上角菜单
3. 选「安装应用 / 添加到主屏幕」
4. 确认，桌面出现图标

Windows（Edge / Chrome）

1. Edge / Chrome 打开公开链接
2. 点地址栏右侧安装图标，或菜单里「将此站点安装为应用」
3. 从开始菜单或桌面快捷方式打开，可固定到任务栏

连接 OneDrive（一次性设置）

用微软官方登录直连 OneDrive，只读写 Finance/finance-data.json。复用 Azure 应用 Muse OneDrive，需先加本页跳转地址：

  1. 打开 Azure 门户 → 应用注册 → 找到 Muse OneDrive（App ID cff5bc5e-6954-419f-924a-e7bcf81fc853）。
  2. 到「身份验证」→ 添加平台 → 选 单页应用。不要加到已有的「移动和桌面」平台。
  3. 跳转地址必须与页面代码完全一致（勿只填域名）：
    https://mmmjp92.github.io/finance-pwa/
    保存。以后连接 OneDrive 都从此链接打开本页。
  4. 回到本页点下方「连接 OneDrive」，登录微软账号并同意 Files.ReadWrite。
  5. 连接后自动首次同步：拉取云端、合并、再推回。之后打开拉取、记账后推送。

若报 AADSTS50011（跳转地址不匹配），即第 3 步未加或未保存，按上补好再试。此步只能在 Azure 门户完成。

金额均为 CAD（标 USD 除外）。数据存本地并同步 OneDrive；预置余额为 $0，导入随手记历史（2,151 条）或手动对账后更新。
