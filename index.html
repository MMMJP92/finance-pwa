虚拟账户：预留不算可用 推荐用法

TD for Rent 就是这个用法：每月从 TD Chequing 转 CAD $2,100 进去，再付 CAD $2,100 房租。钱确实在账上，但已经 set aside 给未来必付的房租，所以不计入可用余额和净资产，总览单独显示「已预留」，避免高估自己手头有多少钱。TD to Lili 同理。

比起不建这个账户、只在心里记着，虚拟账户的好处是：转账记录完整可查、房租到期直接从预留里付、可用余额永远是真实能花的数。

装到桌面（像 App 一样打开）

先用手机或电脑的浏览器打开本页的公开链接，再按下面对应设备的步骤装一次。装好后从桌面图标打开是全屏独立窗口，不用再进 Muse。要说清楚的是：当前托管方式下离线缓存管不到页面本身（顶部状态栏「离线外壳」一项会如实显示），所以完全断网冷启动仍需联网加载一次页面；页面打开后断网可以照常记账，数据都存本机，联网后自动同步回 OneDrive。

iPhone / iPad（Safari）

1. 用 Safari 打开公开链接
2. 点底部分享按钮（方框带上箭头）
3. 选「添加到主屏幕」→「添加」
4. 以后从桌面图标打开，不要在 Muse 里开

Android（Chrome）

1. 用 Chrome 打开公开链接
2. 点右上角 ⋮ 菜单
3. 选「安装应用」/「添加到主屏幕」
4. 确认安装，桌面会出现图标

Windows（Edge / Chrome）

1. 用 Edge 或 Chrome 打开公开链接
2. 点地址栏右侧的安装图标（显示器带下箭头），或菜单里选「将此站安装为应用」
3. 装好后开始菜单 / 桌面都有入口，可固定到任务栏

小提醒：从桌面图标打开仍需要网络加载页面（离线外壳暂未覆盖页面，见顶部状态栏）；页面打开后断网可继续记账，新记录存本机、联网后自动补同步。重要数据始终以 OneDrive 里的 finance-data.json 为准。

连接 OneDrive（只需设置一次）

本页用微软官方登录（MSAL，浏览器端 PKCE，无密钥）直连你的 OneDrive，只读写 Finance 文件夹里的 finance-data.json 一个文件。沿用已有的 Azure 应用「Muse OneDrive」，但要先给这个网页补一个跳转地址：

  1. 打开 Azure 门户 →「应用注册」→ 找到应用 Muse OneDrive（应用 ID cff5bc5e-6954-419f-924a-e7bcf81fc853）。
  2. 进「Authentication（身份验证）」→「Add a platform（添加平台）」→ 选 Single-page application（单页应用程序）。注意不要加到已有的 Mobile and desktop 平台里，那是给 Muse 服务端用的。
  3. 跳转 URI 就填下面这一条（与本页代码里配置的登录跳转地址逐字一致，不要改成只填域名）：
    https://mmmjp92.github.io/finance-pwa/
    保存。以后连接 OneDrive 都从这个公开链接打开本页，登录才能对上。
  4. 回到本页点下面的「连接 OneDrive」，用你的微软账号登录并同意 Files.ReadWrite 权限。
  5. 连接成功后会自动完成第一次同步：拉取云端 finance-data.json 合并，再把合并结果推回云端。之后打开自动拉、记账自动推，不用再管。

如果点连接后微软报错 AADSTS50011（redirect URI mismatch），就是第 3 步的地址还没加或没保存，按上面补好再试；这一步只能在你的 Azure 门户里做，网页自己改不了。

金额均为 CAD，除非标注 USD。数据保存在本机并同步到 OneDrive 的 finance-data.json；离线记账联网后自动补同步。预置账户余额为 CAD $0，导入随手记历史（2,151 条收支）或手动对账后更新。
