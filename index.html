Virtual Accounts: Reserved Does Not Count as Available Recommended

TD for Rent works exactly this way: each month you transfer CAD $2,100 in from TD Chequing, then pay CAD $2,100 in rent. The money is really in the account, but it is already set aside for upcoming rent, so it does not count toward available balance or net worth. The overview shows it separately as Reserved so you do not overestimate what you have to spend. TD to Lili works the same way.

Compared with just keeping it in your head, a virtual account keeps a complete transfer trail, lets you pay rent directly from the reserve when it is due, and keeps your available balance honest.

OneDrive Direct Sync Automatic

Once you connect your Microsoft account: the app pulls and merges the latest cloud data on open, and pushes automatically to OneDrive Finance/finance-data.json after each entry. You can keep bookkeeping offline while the page is open — new entries queue locally as Pending and push automatically when you are back online. Sign-in state and tokens are stored only in your browser and never pass through any server. Setup steps are in the Install / Connect tab.

Add to Home Screen (Open Like an App)

Open the public link for this page in your phone or computer browser first, then follow the steps for your device below to install it once. After that, opening from the home-screen icon gives you a full-screen standalone window — no need to go through Muse. To be clear: with the current hosting, the offline cache cannot cover the page itself (the Offline Shell item in the status bar shows this honestly), so a fully offline cold start still needs network to load the page once. Once the page is open you can bookkeep offline — data is stored locally and syncs back to OneDrive when you reconnect.

Connect OneDrive (One-time Setup)

This page connects directly to your OneDrive using Microsoft official sign-in (MSAL, browser PKCE, no secrets) and only reads and writes the single finance-data.json file in the Finance folder. It reuses the existing Azure app Muse OneDrive, but you need to add a redirect URI for this web page first:

  1. Open the Azure Portal, go to App registrations, and find the app Muse OneDrive (App ID cff5bc5e-6954-419f-924a-e7bcf81fc853).
  2. Go to Authentication, Add a platform, and choose Single-page application. Do not add it to the existing Mobile and desktop platform — that one is for the Muse server.
  3. Use exactly this redirect URI (it must match the sign-in redirect in this page code character-for-character — do not shorten it to just the domain):
    https://mmmjp92.github.io/finance-pwa/
    Save. From now on, always open this page from this public link when connecting OneDrive, so sign-in matches.
  4. Come back to this page, click Connect OneDrive below, sign in with your Microsoft account, and consent to Files.ReadWrite.
  5. After connecting, the first sync runs automatically: it pulls the cloud finance-data.json, merges it, and pushes the merged result back. After that it pulls on open and pushes after each entry.

If Microsoft returns AADSTS50011 (redirect URI mismatch) after you click Connect, the URI in step 3 has not been added or saved yet — add it as above and try again. This step can only be done in your Azure Portal; the web page cannot change it for you.
